## Limites et travail restant
- Audit partiel, aucune garantie d'absence de faille.
- Test en base avec deux comptes de fixture créés dans une transaction : lecture limitée à ses données, modification de son profil autorisée, modification/suppression du profil tiers refusée, réattribution du propriétaire refusée, auto-promotion superadmin refusée, RPC admin refusé, accès aux profils/données refusé après désactivation. Résultat PASS ; transaction annulée ; aucun compte de test restant.
- Ces fixtures ne sont pas des connexions navigateur : parcours de connexion, émission de JWT et sessions via deux vrais clients restent à tester.
- Protection des mots de passe compromis encore désactivée ; fonctionnalité Pro+ selon documentation Supabase. Abonnement réel et possibilité d'activation non vérifiés.
- Politique CSP complète et protection contre les abus distribués des API à approfondir. Le limiteur de l'assistant est local à une instance et ne constitue pas un quota global.
- npm audit ne couvre pas les scripts chargés par CDN ni toutes les dépendances distantes des fonctions Edge.
